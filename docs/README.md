# Project Documentation

Welcome to the documentation repository for the Bike Rental System project.

## Structure

- `api-design/` : REST API specifications, OpenAPI/Swagger docs, and payload schemas.
- `architecture/` : System architecture diagrams, tech stack overviews, and component blueprints.
- `meeting-notes/` : Records and summaries of team discussions and sprint syncs.
- `requirements/` : Functional & non-functional requirements, user stories, and specifications.
- `ui-design/` : UI/UX wireframes, Figma design links, and screen mockups.
- `workflow/` : Business processes, user journeys, and sequence diagrams.
