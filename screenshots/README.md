# Project Screenshots & Media

This directory stores screenshots, recordings, and visual proof of application functionality and testing.

## Folder Structure

- `frontend/` : User interface screenshots, page design snapshots, and UI workflows.
- `backend/` : Terminal outputs, database queries, server log captures, and API execution proofs.
- `testing/` : Test results, coverage reports, and automated test execution screenshots (Postman, Jest, JUnit, etc.).
