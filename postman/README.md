# Postman API Collection & Environment

This directory contains the Postman export files to test the API endpoints of the Bike Rental System.

## Files

- `BikeRental.postman_collection.json` : Postman API collection containing requests for authentication, bike management, bookings, users, and payments.
- `BikeRental.postman_environment.json` : Postman environment configuration containing variables such as `baseUrl` and auth tokens.

## How to Use

1. Open Postman.
2. Click **Import** (top left).
3. Select `BikeRental.postman_collection.json` and `BikeRental.postman_environment.json`.
4. Select **Bike Rental Local Environment** as your active environment in Postman.
5. Start testing the API endpoints!
